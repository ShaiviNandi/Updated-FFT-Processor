==============================================================================
MIXED-PRECISION FP4/FP8 CORES - FPGA SYNTHESIS, POWER AND THROUGHPUT
==============================================================================

What this reports: area, achievable clock frequency and dynamic power for the
NSGA-II-selected mixed-precision FFT cores on FPGA, regenerated with the
gated butterfly wrapper, plus the throughput, energy and efficiency figures
derived from them. Same Vivado scripts and same testbench as the FP16 and
FP32 baselines, so the three are comparable by construction.

Target FPGA device              : xc7a35tcpg236-1
Clock period used for power/XDC : 10.0 ns (100.0 MHz constraint)
Butterfly wrapper               : butterfly_wrapper_gated, PIPELINE_OPERANDS=0
                                  (combinational operand isolation, no added latency)
DSP inference for multipliers    : enabled
Synthesis script                : vivado_synthesis_v2.tcl (unmodified)
Switching-activity script       : generate_saif_funcsim.tcl (unmodified)
Activity testbench              : tb_fft_power.v, strip path tb_fft_power/uut
Minimum accepted SAIF coverage  : 10% of design nets

The clock constraint above only sets the operating point at which dynamic
power is reported. Energy per transform is frequency-invariant, so it is the
same physical quantity whatever constraint is used.

  Compute cycles plus 4N + 1: load is N+1 cycles and unload is 3N, from the

  --cycles-file to substitute a measured table.

HOW THE DERIVED COLUMNS ARE COMPUTED
  Throughput (transforms/s)      = maximum frequency / cycles per transform
  Energy per transform (nJ)      = dynamic power x cycles x clock period
  Throughput per watt (transf/J) = 1 / energy per transform. These are the
                                   same quantity, not a separate measurement.
  Throughput per 1000 logic LUTs = throughput / (logic LUTs / 1000)
